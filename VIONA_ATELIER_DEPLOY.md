# VIONA Atelier — полный перезапуск

## Что изменено
Новая главная `public/index.html` построена независимо от старой: собственные `public/atelier/main.css` и `public/atelier/app.js`, стеклянный интерфейс с реальным `backdrop-filter`, внутренними бликами, анимацией капель и отдельной доступной мобильной структурой. Старый опубликованный интерфейс доступен через `/classic` как временный резерв, чтобы не ломать старые функции.

Управление товарами использует существующий `GET /api/products`. Корзина хранит выбранные ID на клиенте. Тестовая оплата отправляет запросы существующим безопасным API:
- `/api/payments/test/init` для банковской карты и размещённой банком платёжной страницы, где может быть T-Pay;
- `/api/payments/test/qr` для СБП;
- `/api/payments/test/sberpay` для SberPay.

Никакой отдельный endpoint T-Pay не выдумывается: его фактическое появление на странице Т-Банка зависит от настройки и возможностей терминала. Статусы платежей подтверждаются сервером, а не фактом перехода по URL. Персональные файлы остаются защищены текущей авторизацией.

### Как включить новые поддомены
1. В Render открой сервис, который уже обслуживает `viona.space`.
2. В **Settings → Custom Domains** добавь `soundlab.viona.space`, а затем по необходимости `bots.viona.space`, `web.viona.space`, `code.viona.space`.
3. В панели DNS регистратора домена создай **CNAME** для каждого поддомена по **точному** значению, предложенному Render. Не заменяй A- и CNAME-записи рабочего корневого домена.
4. Проверь статус доменной проверки и выпуска TLS-сертификата в Render; открывай URL только после завершения.
5. Если появляется `ERR_CONNECTION_CLOSED`, сначала проверь статус Custom Domain и TLS, затем корректность записи DNS и применение сертификата. Это не исправляется редактированием HTML.

Просто залить код в GitHub недостаточно, чтобы активировать DNS и HTTPS. До выполнения перечисленного используйте `viona.space/music`.

## SoundLab и артист
- `/music` — отдельная музыкальная форма на базе PostgreSQL `viona_music_requests`.
- `/KANEKANKANARTIST` — полная музыка-ориентированная биография с отдельной визуальной темой.
- `/careers` — отклик сохраняется в `viona_career_applications` через существующий серверный API.
- Изменение статусов заявок, доступ к контактным данным и управление тестовыми заказами остаются за Google-авторизованной админкой.

**Внимание:** музыкальная форма принимает индивидуальные заказы, а не автоматически генерирует аудио. Цена написания текста и срок работы согласуются отдельно; форма сама не списывает деньги.

## Ошибка 502 в тестовой оплате
Новая главная использует серверный код Т-Банка, который отмечает отказ Init как `INIT_FAILED` и возвращает безопасные `code` и `bankCode`. При повторном отказе по адресу `/api/payments/test/init`:
1. Проверь переменные `TBANK_DEMO_TERMINAL`, `TBANK_DEMO_PASSWORD`, `PUBLIC_BASE_URL` и `DATABASE_URL` в Render, **не присылай их значения в чат**.
2. Сохрани только код ошибки (например, `BANK_REJECTED / <bankCode>`), время и способ оплаты.
3. Сверь логи Render по времени, затем обратись в поддержку Т-Банка с безопасным кодом.
4. Не отмечай заказ оплаченным вручную: подтверждённый тестовый платёж проверяется отдельно.

Сам редизайн не доказывает, что внешний отказ 502 устранён.
