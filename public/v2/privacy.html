Политика обработки данных

Предварительная информационная страница. Не является окончательной юридической редакцией. До начала реальной коммерческой деятельности её должен проверить ответственный владелец проекта.

Назначение

VIONA получает только данные, которые пользователь отправляет в формах: контакт, описание задачи, жанр/пожелания для музыки либо навыки для отклика.

Принципы

Данные заявок хранятся в подключённой базе PostgreSQL и доступны ограниченному кругу администраторов. Передача третьим лицам не осуществляется для рекламных рассылок.

Перед коммерческим запуском

Для полного юридического документа нужны сведения о реальном операторе данных, сроках хранения, основаниях обработки, порядке удаления и применимом законодательстве.
